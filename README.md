# SAP Cloud Debugger — UI5 and HTML5 browser diagnostics

Inspect browser network, console, and debugger events through a local Python interface using Chrome DevTools Protocol.

## Before running

Review `main.py` for environment requirements and browser startup behavior. This prototype can close existing Chrome processes; save browser work first. Use it only with applications and browser sessions you are authorized to inspect.

The repository does not yet include a dependency manifest or a verified installation guide. Contributions that document a reproducible setup are welcome.
